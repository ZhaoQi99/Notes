# 操作权限实现
## 权限标识
* 权限标识格式: `f"{basename}_{action}"`
  * `basename`来自Router注册时的`basename`属性
  * `action`来自`View`的`action`属性
* 把`partial_update`映射为`update`
* 对于非`ViewSet`的接口,用`request._request.resolver_match.url_name`获取`url_name`作为权限标识
```python
def get_perm_name(view):
    covert_map = {
        "partial_update": "update",
    }
    if basename := getattr(view, "basename", None):
        action = covert_map.get(view.action, view.action)
        return f"{basename}_{action}"
    if request := view.request:
        return request._request.resolver_match.url_name
    return None
```
## Permission
* 用户-> 角色-> 权限
* `enable`字段,用于动态控制权限
* `category`字段,用于权限分类展示,如"系统管理-用户管理"
* `name`字段,权限名称展示;如"查看","新建","编辑","删除"
* `code_name`字段,支持包含多个权限标识,用逗号分隔,如`user_list,user_update`
  
## 校验逻辑
1. 安全方法（HEAD、OPTIONS）直接放行
2. 超级用户直接放行
3. 调用`Permission.get_perm_name(view)`获取权限标识
4. 若该权限标识在数据库中存在且启用,则检查用户是否拥有该权限
5. 没有启用的权限标识直接放行

# 数据权限实现

## 设计思路
* 数据权限过滤基于 `creator` 字段,所有权限类型最终都回归到`filter(creator__in=user_set)`
* 角色关联多种数据权限,优先级从高到低依次为(前4种存在优先级):
  * 全部数据: 不受限制,返回全部数据
  * 本部门及以下部门: 获取本部门及下级部门的所有用户创建的数据(通过 `User.objects.filter(department__startswith=xx)`)
  * 本部门: 仅获取本部门用户创建的数据(`User.objects.filter(department=xx)`)
  * 本人创建: 仅返回当前用户创建的数据
  * 自定义部门 / 自定义用户: 在以上权限基础上,额外添加指定部门或用户创建的数据

## 过滤逻辑
  1. 判断`Model`是否在权限控制范围内
  2. 检查`Model`是否包含 `creator` 字段,缺失则返回全部数据
  3. 检查用户是否为超级用户,是则返回全部数据
  4. 获取用户角色的最大权限范围,构建可访问的`creator`集合
  5. 若存在自定义权限,额外添加通过 自定义部门下的用户/自定义用户至`creator`集合中
  6. 最终通过 `creator__in=user_set` 过滤查询集

```python title:lib/rest_framework/permissions/role.py
SAFE_METHODS = (HTTPMethod.HEAD.value, HTTPMethod.OPTIONS.value)


class RolePermission(permissions.BasePermission):
    def _has_perm(self, request, perm):
        # TODO: Cache permissions and update cache on userInfo API
        return perm in request.user.get_rbac_permissions()

    def has_permission(self, request, view):
        print(Permission.get_perm_name(view))

        if request.method in SAFE_METHODS:
            return True

        user = request.user
        if user.is_authenticated and user.is_superuser:
            return True

        perm = Permission.get_perm_name(view)
        if (
            Permission.objects.filter(enable=True)
            .extra(where=[f"FIND_IN_SET('{perm}', code_name)"])
            .exists()
        ):
            return self._has_perm(request, perm)
        return True
```

## 核心代码 - 数据权限过滤
```python title:lib/rest_framework/filters.py
from django.apps import apps
from django.conf import settings
from django.db.models import Max, Min
from rest_framework.filters import BaseFilterBackend

from account.models import Role, RoleCustomDataScope, User

DataScope = Role.DataScope


def get_models():
    models = list()
    for app_name, value in settings.NEED_FILTER_DATA_MODEL.items():
        for model_name in value:
            models.append(apps.get_model(app_name, model_name))
    return models


NEED_FILTER_DATA_MODEL = get_models()


def get_department_users(department):
    return User.objects.filter(department=department).values_list("username", flat=True)


def get_department_users_cascade(department):
    return User.objects.filter(department__startswith=department).values_list(
        "username", flat=True
    )


class BaseDataScopeFilter(BaseFilterBackend):
    def get_min_scope(self, user):
        if not hasattr(self, "min_scope"):
            setattr(
                self,
                "min_scope",
                user.roles.aggregate(min_scope=Min("data_scope"))["min_scope"],
            )
        return getattr(self, "min_scope")

    def get_max_scope(self, user):
        if not hasattr(self, "max_scope"):
            setattr(
                self,
                "max_scope",
                user.roles.aggregate(max_scope=Max("data_scope"))["max_scope"],
            )
        return getattr(self, "max_scope")

    def get_user_set(self, request):
        user = request.user

        user_set = set()
        user_set.add(user.username)

        min_scope = self.get_min_scope(user)

        if min_scope == DataScope.ONLY_SELF:
            pass
        if min_scope == DataScope.DEPARTMENT_CASCADE:
            user_set = user_set.union(
                set(get_department_users_cascade(user.department))
            )
        elif min_scope == DataScope.DEPARTMENT:
            user_set = user_set.union(set(get_department_users(user.department)))

        max_scope = self.get_max_scope(user)
        if max_scope == DataScope.CUSTOM:
            roles = list(
                user.roles.filter(data_scope=DataScope.CUSTOM).values_list(
                    "pk", flat=True
                )
            )
            for owner, custom_type in RoleCustomDataScope.objects.filter(
                role__in=roles
            ).values_list("owner", "custom_type"):
                if custom_type == RoleCustomDataScope.CustomType.DEPARTMENT:
                    user_set = user_set.union(get_department_users_cascade(owner))
                elif custom_type == RoleCustomDataScope.CustomType.USER:
                    user_set.add(owner)

        return user_set

class CreatorDataScopeFilter(BaseDataScopeFilter):
    def filter_queryset(self, request, queryset, view):
        model = queryset.model
        user = request.user

        if model not in NEED_FILTER_DATA_MODEL:
            return queryset

        if not hasattr(model, "creator"):
            return queryset

        if user.is_superuser is True:
            return queryset

        min_scope = self.get_min_scope(user)
        if min_scope == DataScope.ALL:
            return queryset
        elif min_scope is None:
            return queryset.none()

        user_set = self.get_user_set(request)
        return queryset.filter(creator__in=user_set)
```

```python title:account/models/permission.py
class Permission(BaseModel):
    """权限"""

    code_name = models.CharField(max_length=128, verbose_name="权限标识")
    name = models.CharField(max_length=100, verbose_name="权限名")

        db_table = "permission"

    @staticmethod
    def get_perm_name(view):
        covert_map = {
            "partial_update": "update",
        }
        if basename := getattr(view, "basename", None):
            action = covert_map.get(view.action, view.action)
            return f"{basename}_{action}"
        if request := view.request:
            return request._request.resolver_match.url_name
```

```python title:account/models/role.py
from django.db import models

from account.models import Permission
from lib.base.models import BaseModel
from lib.django_softdelete_mixin.constant import UN_DELETE


class Role(BaseModel):
    """角色表"""

    class DataScope:
        ALL = 0
        DEPARTMENT_CASCADE = 1
        DEPARTMENT = 2
        ONLY_SELF = 3
        CUSTOM = 4

    DATA_SCOPE_CHOICES = (
        (0, "全部数据权限"),
        (1, "本部门及以下数据权限"),
        (2, "本部门数据权限"),
        (3, "仅本人数据权限"),
        (4, "自定数据权限"),
    )
    name = models.CharField("名称", max_length=64)
    desc = models.CharField("描述", max_length=128, null=True, blank=True, default="")
    _permissions = models.ManyToManyField(
        Permission,
        through="RolePermission",
        blank=True,
        verbose_name="权限",
        related_name="roles",
    )
    data_scope = models.PositiveSmallIntegerField(
        "数据范围",
        choices=DATA_SCOPE_CHOICES,
        default=DataScope.ONLY_SELF,
        null=False,
        blank=False,
    )

    class Meta:
        db_table = "role"
        verbose_name = "角色"
        verbose_name_plural = verbose_name
        unique_together = (("name", "deleted"),)

    def __str__(self):
        return f"{self.name}"

    @property
    def permissions(self):
        return self._permissions.filter(role_permission__deleted=UN_DELETE)

    @property
    def users(self):
        return self.user_set.filter(role_user__deleted=UN_DELETE)


class RolePermission(BaseModel):
    role = models.ForeignKey(
        Role, related_name="role_permission", on_delete=models.CASCADE
    )
    permission = models.ForeignKey(
        Permission, related_name="role_permission", on_delete=models.CASCADE
    )

    class Meta:
        db_table = "role_permission"
        verbose_name = "角色-权限"
        verbose_name_plural = verbose_name

    CUSTOM_TYPE_CHOICES = (

        (CustomType.USER, "自定义用户"),

    role = models.ForeignKey(
```

```python title:account/models/user.py
from functools import reduce

from django.contrib.auth.models import AbstractUser
from django.contrib.auth.models import UserManager as BaseUserManager
from django.db import models

from account.models import RolePermission
from lib.base.models import BaseModel
from lib.django_softdelete_mixin.constant import UN_DELETE
from lib.django_softdelete_mixin.mixins import SoftDeleteManagerMixin


class UserManager(SoftDeleteManagerMixin, BaseUserManager):
    use_in_migrations = True

    def _create_user(self, username, email, password, **extra_fields):
        extra_fields.pop("is_staff")
        return super()._create_user(username, email, password, **extra_fields)


class User(BaseModel, AbstractUser):
    """用户表"""

    first_name = None
    last_name = None
    groups = []
    user_permissions = []

    objects = UserManager()

    real_name = models.CharField("真实姓名", max_length=64, db_index=True)
    email = models.CharField("邮箱", max_length=64, db_index=True)
    phone = models.CharField("手机号", max_length=32, db_index=True, default="")
    department = models.CharField("部门", max_length=255, null=True, blank=True)
    comment = models.CharField("描述", max_length=128, null=True, blank=True)
    _roles = models.ManyToManyField(
        "Role", through="RoleUser", verbose_name="角色", blank=True
    )

    class Meta:
        db_table = "user"
        verbose_name = "用户"
        verbose_name_plural = verbose_name
        # 手动删除DB的 UNIQUE(`username`) -> ALTER TABLE `user` DROP INDEX `username`;
        unique_together = (("username", "deleted"),)

    @property
    def roles(self):
        return self._roles.filter(role_user__deleted=UN_DELETE)

    def get_rbac_permissions(self):
        roles = list(self.roles.values_list("id", flat=True))
        queryset = (
            RolePermission.objects.filter(role__in=roles)
            .values_list("permission__code_name", flat=True)
            .distinct()
        )
        permission_set = reduce(lambda x, y: x | set(y.split(",")), queryset, set())
        return list(permission_set)

    @property
    def is_staff(self):
        return self.is_superuser


class RoleUser(BaseModel):
    role = models.ForeignKey("Role", related_name="role_user", on_delete=models.CASCADE)
    user = models.ForeignKey(User, related_name="role_user", on_delete=models.CASCADE)

    class Meta:
        db_table = "role_user"
        verbose_name = "角色-用户"
        verbose_name_plural = verbose_name

    def __str__(self) -> str:
        return f"{self.role}-{self.user}"
```

## 更细粒度的权限控制
1. 共享本人名下部分数据给某人
  * 新增另一张表(id,model_name,resource_id,username)
  * 沿用按照`creator`过滤的逻辑,通过`model_name`从该表获取该用户有权限访问资源的主键ID
  * `Q`表达式: `queryset.filter(Q(creator__in=xx)| Q(pk__in=xxx))`

## 问题
1. 组织架构调整
  * 当前数据权限强依赖 `department` 层级关系（如 `startswith`），组织结构变更后数据可见范围会随之变化。
  * 影响:权限结果不稳定，容易出现“昨日可见、今日不可见”或越权可见的情况。
  * 解决方案:用户在登录时会同步最新部门;定时任务同步用户最新部门.对于`本部门`、`本部门及以下部门` 、`自定义用户`无影响,对于`自定义部门`权限,仍会会导致权限失效。
2. 用户异动 / 用户离职
  * 用户异动后,数据归新部门所有,会导致数据归属与实际管理关系不一致;可手动修改`creator`,但会影响审计追踪
  * 用户离职后,在组织架构调整前无影响;组织架构调整后,会导致同部门其他成员无法继续访问其历史业务数据。
3. 模型权限粒度固定
  * 各`Model`复用同一套权限粒度与过滤策略
  * 无法满足某些`Model`需要更细粒度的权限控制需求,如按照某个字段进行权限过滤
